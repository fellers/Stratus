# Stratus
*A modular autonomous drone platform exploring embedded systems, robotics, and flight software through first-principles engineering.*

## Mission

Stratus is a long-term engineering project focused on designing an autonomous quadcopter from the ground up. The project emphasizes embedded firmware, control systems, mechanical design, electronics, and modular architecture over off-the-shelf solutions.

The project emphasizes:

- Embedded Systems
- Flight Control
- Robotics
- PCB Design
- Mechanical Engineering
- Systems Engineering

rather than assembling commercial flight components.

## Goals

- Stable hover
- Sensor fusion
- GPS navigation
- Custom PCB
- Vision
- Autonomous missions

## Project Philosophy

- First build for learning and cost efficiency, then for performance
- Favor modularity over optimization
- Every revision should remove one unknown
- Prefer documented decisions over intuition
- Components should be reusable across revisions whenever practical
