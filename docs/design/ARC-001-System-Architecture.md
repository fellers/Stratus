# 1. Purpose

This document defines the architecture of the Stratus Rev A platform and describes the decomposition of the system into independent subsystems and their interactions.

---

# 2. Architectural Principles

- Modularity
- Separation of Concerns
- Hardware Abstraction
- First-Principles Engineering
- Extensibility
- Maintainability
- Fault Tolerance

---

# 3. System Context

Stratus is an autonomous aerial robotics platform consisting of interconnected Mechanical, Electrical, and Software subsystems.

---

# 4. Subsystem Overview

## Flight Control

Responsible for aircraft stabilization and control.

## State Estimation

Responsible for estimating aircraft orientation and future vehicle state.

## Motor Output

Responsible for generating motor-specific commands.

## Propulsion

Responsible for generating thrust.

## Communications

Responsible for debugging, telemetry, and future command interfaces.

## Mechanical Structure

Responsible for supporting and protecting onboard systems.

## Power Distribution

Responsible for supplying power to onboard systems.
